Local-only demonstration of durable escalation state using FastAPI, SQLAlchemy, SQLite, and Alembic. No external integrations are called.

## Setup (Arch Linux / Bash)

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
alembic upgrade head
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Open `http://127.0.0.1:8000/docs`.

## Try the workflow

```bash
curl -sS -X POST http://127.0.0.1:8000/webhooks/zendesk -H 'Content-Type: application/json' -d '{"ticket_id":1042,"agent_id":17,"issue":"Charging fails intermittently"}' | python -m json.tool
# Copy escalation_id from the response into the following URLs
curl -sS -X POST http://127.0.0.1:8000/mock/chat-replies/ESCALATION_ID -H 'Content-Type: application/json' -d '{"manager_id":5,"message":"Inspect charger harness"}' | python -m json.tool
curl -sS -X POST http://127.0.0.1:8000/mock/complete/ESCALATION_ID | python -m json.tool
curl -sS http://127.0.0.1:8000/escalations/ESCALATION_ID/events | python -m json.tool
```

Restart the server and query the escalation ID again: it persists in `escalations.db`.

# escalation-poc

Python-based technical support escalation management system that automates workflows between Zendesk, Google Chat, Claude AI, and internal vehicle databases. Streamlines ticket escalation, AI-assisted diagnostics, manager collaboration, and resolution tracking through event-driven automation.

## Scope and limitations

- The mock webhook and reply routes are **not authenticated**. Bind to localhost only; do not expose to the internet.
- External work is synchronous and simulated; real delivery requires a durable job/outbox and retry handling.
- Active-ticket uniqueness is enforced by a SQLite partial unique index; PostgreSQL needs its own migration/index dialect.
- A repeat request for an active ticket is deduplicated; a repeat event after completion may create a new escalation. Future work should add an explicit source event ID and unique constraint.
- The `failed` state is reserved for future worker integration. A real workflow must distinguish retryable failures from terminal failures.
- The mock completion endpoint simulates successful Zendesk updates; it is not proof of an external side effect.
- SQLite stores timezone-aware Python datetimes without preserving offsets by default. Normalize to UTC when exposing timestamps in later iterations.
